# 리치 마작 연습실

**현재 버전: 0.2.3**

한 국을 플레이하고, 타패 효율과 기본 수비 단서를 연습한 뒤 당시의 선택을 복기하는 브라우저용 리치 마작 연습 앱입니다.

[웹에서 리치 마작 연습실 열기](https://toki963.github.io/riichi-solo-trainer/)

## 할 수 있는 것

- **탁자 연습:** AI 3명과 동1국을 플레이합니다. 내 턴부터 시작하거나 동가인 상대의 첫 타패부터 시작할 수 있습니다.
- **패효율 연습:** 버림 후보별 샹텐 수와 보이는 패를 제외한 미확인 유효패 매수를 비교합니다.
- **수비 훈련:** 현물, 스지, 간단한 벽 단서를 확인합니다. 계산하지 않는 론 확률을 숫자로 보여 주지 않습니다.
- **국 복기:** 타패 당시의 손패와 공개 정보를 다시 확인합니다. 판단 점수는 화료·방총 결과와 분리해 계산합니다.
- **기록과 설정:** 완료 기록과 설정은 브라우저에 저장합니다. 기록은 JSON 파일로 내보내거나 다시 가져올 수 있습니다.
- **화면 조정:** 라이트·다크 테마, 타일 이미지·문자 표시, 적도라, 특수형 분석, AI 난이도와 시작 순서를 설정할 수 있습니다.

## 사용 방법

웹 버전은 위 링크에서 열 수 있습니다. 직접 실행하려면 프로젝트 폴더에서 로컬 웹 서버를 시작하고 브라우저로 접속하세요.

```bash
python -m http.server 8000
```

그다음 `http://127.0.0.1:8000`을 엽니다. 일부 브라우저는 `index.html`을 직접 열었을 때 저장 동작에 차이가 있으므로 로컬 서버 사용을 권장합니다.

## 기록 및 외부 연결

게임 상태, 설정, 완료 기록은 현재 브라우저의 로컬 저장소에만 보관되며 서버로 전송되지 않습니다. 브라우저 저장 데이터를 지우면 기록도 사라질 수 있으니 중요한 기록은 **기록 내보내기**로 백업하세요.

이미지 타일은 외부 저장소에서 불러옵니다. 연결할 수 없을 때는 문자 타일로 바꾸거나 설정에서 이미지 없는 표시를 켤 수 있습니다.

## 지원 범위와 한계

현재 앱은 **4인 동1국 연습용 프로토타입**입니다. 일반형·치또이츠·국사무쌍의 샹텐과 기본적인 역·도라·점수 계산, 쯔모·론·리치 및 유국 흐름을 지원합니다.

치·퐁·깡, 복수 론, 남장·오라스 진행, 완전한 점수 심판, 정량적인 상대 론 위험 계산은 지원하지 않습니다. AI와 복기 평가는 학습을 돕는 휴리스틱이며 실제 강자 수준이나 대국 결과를 보증하지 않습니다. 근거가 부족한 항목은 평가에서 제외합니다.

## 개발 확인

Node.js가 설치되어 있으면 자동 테스트를 실행할 수 있습니다.

```bash
node test.js
```

주요 파일은 `index.html`(화면), `app.js`(게임·저장·화면 동작), `engine.js`(규칙·분석), `styles.css`(화면 스타일), `test.js`(자동 테스트)입니다.
