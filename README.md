# 리치 마작 연습실

모바일 세로 화면에서 한 국을 플레이하고, 타패 효율과 기본 수비 단서를 학습하며, 선택 기록을 복기하는 브라우저 기반 프로토타입입니다. 서버·빌드 도구·외부 자바스크립트 라이브러리 없이 HTML/CSS/JavaScript로 실행되는 프로토타입 v0.2.1입니다. 마작 패 그림은 FluffyStuff 타일 세트의 SVG를 사용합니다.

## 웹에서 실행

[리치 마작 연습실 열기](https://toki963.github.io/riichi-solo-trainer/)

## 실행 방법

1. ZIP을 압축 해제합니다.
2. `riichi-solo-trainer` 폴더에서 터미널을 엽니다.
3. 아래 명령을 실행합니다.

```bash
python -m http.server 8000
```

4. 브라우저에서 `http://127.0.0.1:8000`을 엽니다.

`index.html`을 직접 열어도 실행될 수 있지만, 브라우저의 `file://` 저장소 정책 차이를 피하려면 로컬 서버 실행을 권장합니다. 핵심 게임 로직은 로컬에서 동작하지만, 이미지 모드의 타일 그림은 외부 저장소에서 불러옵니다. 인터넷이 끊기거나 이미지가 로드되지 않으면 해당 패는 문자 표시로 자동 대체되며, 기록·설정에서 전체 텍스트 패 표시 모드를 켤 수도 있습니다.

## 구성 파일

- `index.html` — 앱 화면과 내비게이션
- `styles.css` — 모바일 우선 반응형 UI
- `engine.js` — 타일, 샹텐, 유효패, 타일 공개 정보, 기본 화료 및 AI 로직
- `app.js` — 게임 진행, 저장, 훈련 화면, 타패 기록 및 복기
- `test.js` — 엔진 자동 테스트

화면 설정에는 라이트/다크 테마, 이미지 없는 텍스트 패 표시, 내 턴/상대 턴 시작 유형이 있습니다. 이미지 표시가 기본값이며, 설정은 브라우저 로컬 저장소에 저장됩니다. 상대 선공 모드에서는 상대가 동가가 되어 14장으로 시작 패를 버리고, 이후 좌석 순서대로 턴이 진행됩니다.

## 테스트 실행

Node.js가 설치되어 있다면 폴더에서 다음을 실행합니다.

```bash
node test.js
```

외부 패키지 설치는 필요하지 않습니다.

## 사용 흐름

- **탁자:** 내 손패를 터치해 선택한 뒤 타패 버튼을 누릅니다. 일반 플레이에서는 최적 타패를 미리 노출하지 않습니다. 힌트는 직접 요청할 수 있습니다.
- **패효율:** 별도 연습 손패에서 버림 후보별 샹텐, 유효패 종류와 보이는 타일 기준 남은 매수를 비교합니다.
- **수비 훈련:** 상대의 버림패를 보고 현물·스지·벽 단서를 활용해 선택을 연습합니다. 수치 론 확률은 표시하지 않습니다.
- **국 복기:** 기록된 당시 손패와 공개 정보를 기준으로 행동을 다시 봅니다. 상대의 숨은 손패는 국이 종료된 뒤에만 공개됩니다.
- **기록·설정:** 로컬 기록과 설정을 관리하고 JSON 내보내기/가져오기를 합니다.

## 규칙·정확성 범위

현재 버전은 **기본 4인 동1국 학습 프로토타입**입니다. 기본 흐름, 쯔모·론 선택, 리치 일부, 유국, 기본 역/도라/점수 분석, 일반형·치또이츠·국사무쌍 샹텐, 타패 후보 비교, 현물·스지·간단한 벽 단서가 구현되어 있습니다.

다음은 완전 구현되지 않았거나 미지원입니다.

- 치·퐁·깡과 깡 후 린샹 처리
- 복수 론, 다수의 특수 상황 및 역/점수 계산 전반에 대한 공식 규칙 엔진 수준 보장
- 노텐 벌점과 유국 후 점수 조정, 동장·남장 진행 및 오라스 전략
- 정량적인 상대 론 위험 확률 및 숨은 손패 추정
- AI 실력의 강자 수준 검증

따라서 결과 화면의 점수·역 분석은 지원 범위에 한정된 값이며, 공식 대국의 판정용으로 사용하지 마세요. 계산 근거가 없는 위험 확률은 만들어 표시하지 않습니다.

## 데이터 및 개인정보

게임 진행 상태, 설정, 완료 기록은 같은 브라우저의 `localStorage`에 저장됩니다. 브라우저 데이터 삭제 또는 비공개 창 종료 시 기록이 사라질 수 있으므로 기록·설정 화면의 JSON 내보내기를 권장합니다. 데이터는 서버로 전송되지 않습니다.
